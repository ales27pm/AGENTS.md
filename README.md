# AGENTS.md Operations Suite

A lightweight yet opinionated toolkit for running repo-native AI coding agents (e.g., OpenAI's Codex successors) inside
GitHub Actions. The repository provides the contracts agents must follow, reusable workflows that orchestrate lint →
typecheck → tests → reasoning loops, and documentation for maintainers who need deterministic, auditable automation.

## Features

- **Codified contract**: `AGENTS.md`, `PLAYBOOK.md`, and `REPORTING.md` define expectations for tooling, iteration order,
  and the LettlReport schema agents must produce.
- **Reusable automation**: Drop-in workflows (`agent-orchestrate`, `agent-pr-comment`, `agent-reusable`) that bootstrap an
  LLM-driven maintenance loop for any repository.
- **Stack-aware gating**: `scripts/autodetect.sh` inspects manifests (Node, Deno, Bun, Python, Go, Rust, Android, PHP, Ruby, etc.)
  and surfaces the appropriate install/lint/typecheck/test commands for CI.
- **In-repo quality gates**: Local npm tooling (`npm run lint`, `npm run typecheck`, `npm test`) validates docs, shell scripts,
  and the autodetect flow before shipping changes.
- **Audit-friendly artifacts**: Every run captures prompts, logs, and reports for reproducibility and post-mortems.
- **Benchmark dashboards**: `rpi4/bench/pi_bench.py` now emits JSON summaries that power a Textual UI dashboard in
  `automation/ui_app.py`, keeping Raspberry Pi performance trends front-and-center for operators.
- **Ops playbook**: `docs/` packages onboarding, lifecycle, and troubleshooting guidance for platform and security teams.

## Quick Start

1. **Configure secrets**
   - `ANTHROPIC_API_KEY` and/or `OPENAI_API_KEY` scoped to the repository or organization.
2. **Wire the reusable workflow**
   - Call `.github/workflows/agent-reusable.yml` from the target repository, or copy this repo as a subtree.
3. **Trigger a run**
   - Open a pull request or dispatch `agent-orchestrate` manually in `analyze` mode.
4. **Review outputs**
   - Download the workflow artifacts or read the PR comment generated by `agent-pr-comment`.

## Developer workflow

Use the bundled npm scripts to keep changes production-ready:

```bash
npm install           # one-time setup
npm run lint          # markdown + shell validation
npm run typecheck     # TypeScript compiler (configuration sanity)
npm test              # Jest regression suite for autodetect
npm run format        # Prettier across Markdown/YAML/JSON/shell/js
```

Refer to [docs/maintenance.md](docs/maintenance.md) for the broader operational cadence, yamllint expectations, and the
process for extending `scripts/autodetect.sh` with new ecosystems.

## Extending the Agent Loop

- **Additional gates**: Insert security or compliance scanners after the default tests step.
- **Prompt customization**: Centralize modifications in a helper script (e.g., `scripts/render-prompt.sh`) so they remain traceable.
- **Provider swaps**: Adjust default model IDs in workflows and document reasoning changes in PR summaries.

For an architectural deep dive start with [docs/overview.md](docs/overview.md) and [docs/workflows.md](docs/workflows.md).
